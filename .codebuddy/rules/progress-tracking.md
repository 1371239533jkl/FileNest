# 进度与技术债维护

每段交付结束、回复用户之前，必须完成三件事：

1. **核对**：把本轮回复里将要写的"跳过 / 未做 / 风险 / 暂缓"，逐条对照 `docs/PROGRESS.md` 的「已知问题 / 技术债」表。已有条目更新描述，缺失的追加新行（编号顺延）。
2. **关闭**：本轮真正完成的债项，从表中**删除该行**（不要留"已完成"的勾）；随后在表下方的「核对记录」追加一行：日期 / 变更条目编号 / 一句话说明。
3. **同步**：「已完成」表格（附证据路径 + 实测数字）、首行完成度、「下一步」第一条。

提交时，commit 正文必须包含本轮未做项，措辞与 `docs/PROGRESS.md` 一致。

**禁止**只在对话里说"跳过"，而不落表。若确实无法判断是否属于债，按债记录。

完成度按里程碑加权估算，不凭感觉给数。
