# FileNest v2.4.0 发布说明

> 合并发布：批次 1-3（底座稳定 + 效率闭环 + 空间治理），P0 核心能力全部落地。
> 从 v2.1.0 起累计 146 项测试全部通过。

## ✨ 新增功能

### 🏗️ 底座稳定（批次 1）
- **增量索引自动落库**：文件变化（新增/修改/移动/删除）自动更新索引，事件风暴合并、单文件失败重试，不再需要手动重扫
- **内容索引指纹增量**：正文索引按文件修改指纹（大小+时间）增量更新，未变化的文件不重复提取

### ⚡ 效率闭环（批次 2）
- **高级搜索语法**：自然语言解析全量容错（特殊字符不崩溃），结构化条件回显，内置语法提示
- **智能集合**：搜索条件一键保存为集合，入库持久化，随时复用
- **可视化整理规则**：规则管理界面，增删改、启停、优先级排序、按文件名测试命中
- **操作计划模型**：批量操作先生成计划（影响范围/冲突/不可逆项/释放空间），过期自动重校验

### 🧹 空间治理（批次 3）
- **多阶段重复检测**：大小 → 快速哈希 → 完整哈希三级确认，中断可续算，未完整校验不误判重复
- **安全清理中心**：聚合重复/临时/空/长期未用/超大文件建议，一键移入回收区（可撤销），支持排除目录与误报反馈
- 主页面重复文件与多阶段检测打通，数据源统一为权威检测结果

### 🎨 界面优化
- 日历弹层主题修复（深/浅色模式正常显示）
- 清理中心对话框主题与按钮布局优化

## 🐛 修复
- QDateEdit 日历弹层浅色模式黑白混杂、数字排列异常
- QThread 生命周期崩溃（清理中心/多阶段检测线程）
- 清理中心浅色模式黑色背景、按钮错位

## 📦 安装与升级
- 直接替换旧版本即可，数据库自动兼容迁移（无数据丢失）
